# 플레이 출시 노트는 왜 애플 것과 따로 있나

`store/android/ko-KR/release_notes.txt` 가 플레이로 나가는 노트다.
`store/ios/ko/release_notes.txt` 를 그대로 쓰지 않는다.

까닭 — **앱에 있는 기능이 두 스토어에서 같지 않다.**

2026-09-12 에 실제로 걸렸다. 애플 노트의 마지막 줄은
"설정에서 최신 버전을 확인하고 바로 업데이트할 수 있습니다" 였는데,
그 기능은 **앱스토어 판에만 붙어 있다**(`lib/core/update_check.dart` 는
아이튠즈 조회를 쓴다). 안드로이드 이용자에게는 없는 얘기라서 뺐다.

`tool/play_upload.py` 는 이 파일을 먼저 찾고, 없으면 애플 것으로 물러선다.
**물러선 경우에는 반드시 눈으로 한 번 읽어라.** 아이폰·아이패드·앱스토어·
아이클라우드 같은 말이 섞여 들어가면 구글이 '오해를 부르는 설명'으로 본다
(`tool/store_check.py` 의 `PLAY_FORBIDDEN` 과 같은 이유다).
