# 맥 앱스토어 문안

2026-09-13 신설. 맥 판은 아이폰 판과 **같은 앱 기록**에 붙는다(유니버설 구매).
그래서 이름·부제·개인정보·나이 등급은 아이폰 것을 그대로 물려받고, 여기에는
**판마다 다른 글**만 둔다.

- `<locale>/release_notes.txt` — 맥 판의 '새로운 기능'. 아이폰 문안을 그대로
  쓰면 '자판이 올라오면' 같은 말이 남아서 따로 쓴다
- 소개말·키워드·홍보 문구는 `store/ios/<locale>/` 것을 그대로 쓴다. 맥에서도
  틀린 말이 없다(동기화 문장이 이미 맥을 말한다). 맥만 다르게 쓰고 싶으면
  같은 이름의 파일을 여기에 두면 그것이 이긴다
- 붙이는 일은 `tool/mac_store.py` 가 한다
