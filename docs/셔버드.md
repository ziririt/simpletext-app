# 심사 없이 내려보내기 — Shorebird 덧판

> **2026-09-14 소유자 결정.** "굳이 앱 심사를 꼭 받지 않아도 되는 기능은 안 받으면
> 좋겠다. 웹앱처럼 하면 좋겠다." → "Shorebird 를 다음 판(3.19)에 실어라. 계정은
> 내가 만들겠다."
>
> 이 문서 하나로 이어서 할 수 있어야 한다.

## 1. 무엇인가 — 소유자에게 설명하던 말 그대로

아이폰에 깔린 앱은 스토어를 거치지 않고는 손댈 수 없다. 다만 애플 규정
**3.3.1(b)** 와 구글 규정은 "해석기 위에서 도는 코드"는 앱의 본래 목적을 바꾸지 않는
한 스토어 밖에서 갱신해도 된다고 못 박아 두었다. 우리 앱의 다트 코드가 그것이다.

Shorebird 는 그 문으로 다트 부분만 내려보내는 서비스다. 앱을 켤 때 새 덧판이 있나
묻고, 있으면 받아 두었다가 **다음에 켤 때** 갈아입는다.

- 되는 것 — 다트 고침 전부(화면·규칙·번역·속도 값). 우리 고침의 열에 아홉
- 안 되는 것 — 원어 코드(아이클라우드 다리·위젯·공유 확장·MainFlutterWindow),
  그림·글꼴 자산, 새 권한, 원어가 든 새 플러그인, 플러터 판 올리기. 이런 판은 심사
- 값 — 무료: 한 달 5,000회 설치. 넘으면 월 20달러(50,000회). (2026-09-14 실측)
- 이것으로 규정을 어기면 Shorebird 약관 위반이다. 우리는 그럴 일이 없다

## 2. 소유자가 할 것 (한 번)

1. https://console.shorebird.dev 에서 구글 계정으로 가입(무료)
2. 맥 터미널에서 `~/.shorebird/bin/shorebird login` — 브라우저가 열리고 로그인하면 끝
3. 담당자에게 "셔버드 붙여라" 한 마디

로그인은 소유자 몫이다. 담당자는 하지 않는다.

## 3. 담당자가 할 것 (소유자 로그인 뒤)

```bash
export PATH="$HOME/.shorebird/bin:$PATH"
cd ~/development/simpletext_app
shorebird init            # 콘솔에 앱을 만들고 shorebird.yaml 을 쓴다(app_id — 비밀 아님, 커밋한다)
flutter pub get
bash tool/verify.sh
```

그다음 3.19 판을 굽는다 — **이 판이 문을 여는 열쇠다.** 이 판이 스토어에 나가야
그 뒤의 덧판이 붙을 데가 생긴다.

```bash
bash tool/appstore_ios.sh          # shorebird.yaml 이 있으면 저절로 shorebird 로 굽는다
bash tool/appstore_android.sh      # 같다. alpha 트랙에 올린다
python3 tool/submit_next.py --prepare && python3 tool/submit_next.py --submit   # 소유자가 말했을 때만
```

## 4. 그 뒤 — 고침을 내보내는 법

```bash
bash tool/patch.sh ios       # 또는 android / both
```

- `lib/version.dart` 를 **올리지 않는다.** 덧판은 스토어에 나가 있는 판(3.19+254)에 붙는다
- 원어 코드·자산이 바뀌었으면 shorebird 가 거절한다. 그때는 판을 새로 굽고 심사
- 설정 화면 오른쪽 위 `ver.3.19 (254) · p2` — **p 숫자가 오르면 갈아입은 것**이다.
  소유자가 "고쳐졌다"를 볼 때 이 숫자를 본다. 빌드 번호는 같은데 동작이 다른 두 앱이
  생기므로 이 표시가 없으면 또 헷갈린다(version.dart 의 DEV 세 글자와 같은 이야기)
- 개발용 판(`tool/deploy.sh`)은 그대로 flutter 로 굽는다. 덧판과 무관하다

## 5. 지금 상태 (2026-09-14 12:00)

- Shorebird CLI 1.6.120 을 맥에 깔았다(`~/.shorebird/bin`). 저장소 플러터 3.44.9 를
  그대로 쓴다(`--flutter-version`) — 플러터를 올리지 않는다
- `pubspec.yaml` 에 `shorebird_code_push` 를 넣었고, `lib/version.dart` 가 덧판 번호를
  읽어 `appVersionLabel` 에 `· pN` 으로 붙인다. Shorebird 가 없는 판에서는 조용히 빈다
- `tool/appstore_ios.sh` 가 shorebird.yaml 이 있으면 shorebird 로 굽는다.
  `tool/appstore_android.sh`(신설) 도 같다. `tool/patch.sh`(신설) 가 덧판을 낸다
- 판 이름을 3.19 (254) 로 올렸다. 3.18 은 아이폰(253)·맥(252) 둘 다 심사 중
- **아직 안 된 것** — 소유자 로그인 → `shorebird init`. 그 전에는 shorebird.yaml 이
  없어서 모든 스크립트가 예전대로(flutter) 돈다
- 맥 앱스토어 판은 아직 shorebird 로 안 굽는다. `shorebird release macos` 는 .app 만
  내놓아서 우리 `appstore_mac.sh`(xcodebuild archive) 와 결이 다르다. 맥은 마우스라
  급하지 않다. 뒤에 붙인다
